# デモ動画

**[mimamoritai-demo.mp4](mimamoritai-demo.mp4)** — 3分11秒 / 1920x1080 / 24fps / 3.7MB / 日本語字幕入り / 音声なし

本番環境（Azure App Service）を実際に操作して画面録画したものです。うまくいくところだけを繋いだのではなく、**AI の指示が拒否される瞬間もそのまま**入れてあります。

## 収録内容

| 時間 | 内容 |
| --- | --- |
| 0:00 | 離れて暮らす高齢の家族を、カメラなしで見守る |
| 0:12 | 本人は移動しないで、ふつうの言葉で家電を操作（「寒いから扇風機つけて」） |
| 0:24 | 実行の前に必ず確認。「はい」で初めて動く |
| 0:48 | 扇風機だけが「使用中」に。電気ストーブは赤枠で区別される |
| 1:00 | 「寒いからストーブつけて」→ **確認すら出さずに拒否**。最終段のルールが必ず止める |
| 1:24 | 「消して」は通る。ON は拒否、OFF は許可 |
| 1:36 | 消すときも、実行前に確認を挟む |
| 2:00 | 家族は LINE で「今日のお母さんの様子は？」と聞くだけ |
| 2:24 | 本人が楽をするための操作が、そのまま家族への便りになる |
| 2:36 | AI・Microsoft Fabric・LINE はすべて実連携（接続状況） |
| 2:48 | 実データを Microsoft Fabric へ送信 |
| 3:00 | 送信完了（50件・836ms・Eventhouse）。本人は移動しなくてよくなり、家族はカメラなしで様子がわかる |

## 補足

- 撮影・編集の方針は [../DEMO_SCENARIO.md](../DEMO_SCENARIO.md) にまとめてあります。
- デモ環境の URL はあえて公開していません。ハッカソン用に立てた Azure リソースなので、審査後は停止する予定です。この動画と [../EVIDENCE.md](../EVIDENCE.md) が、稼働していた証拠になります。
- 手元で動かす場合は `dotnet run` だけで済みます。API キーは要りません（すべてモックに切り替わります）。
